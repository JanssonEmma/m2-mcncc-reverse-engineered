# Game global clock recovery

The original game ELF (SHA25661fa6e736a5b0ff446dfd817dd9a87a42d2bfbcf5da27b7975cb8ae1e2b67a1c) has get_global_time08146c20 and set_global_time08146c40 in utils.cpp. Complete saved Ghidra bodies are in ghidra.json. metadata.json records focused target DWARF signatures: time_t is signed int32 for return and parameter, global_time_gap is static int32 at083259a4. ELF section20 is .bss SHT_NOBITS, proving its initial zero state.

get_global_time reads system time and adds the stored gap. set_global_time subtracts its first system-clock read from the requested time, stores the gap, then calls get_global_time (a second clock read) to format the logged adjusted time. The original local buffer is33 bytes but snprintf limit is32, producing at most31 text characters. sys_log receives level0, format "GLOBAL_TIME: %s time_gap %d". Both arithmetic operations wrap to32 bits in x86; reconstructed code uses unsigned int arithmetic and casts through int so optimized host tests preserve that behavior without signed overflow. Host API declaration remains time_t; target32 structural compilation verifies the intended platform widths.

printdata was already reconstructed at libthecore/src/utils.c190-213, declared by libthecore/include/utils.h27, covered by utils_strings_regression.c150-155. It is not a game utility or a missing dependency and was not duplicated.

game_time_regression.cpp supplies scripted clocks plus isolated time_str/sys_log fixtures. It checks initial zero gap, forward/backward adjustment, the two distinct clock reads during set, format/truncation and signed32 boundary wrap. Only the game module is compiled with forced include game_time_hooks.h to replace its clock; the fixture compiles normally. O0 and O2 pass. Module compiles with -m32 -D_GLIBCXX_USE_CXX11_ABI=0 -D_USE_32BIT_TIME_T. No original binary execution or full FreeBSD runtime comparison was performed. Remaining utils.cpp functions are outside this bounded recovery.
