# Entity and sector recovery

CEntity retains its complete old data/virtual declaration and source placement across entity.cpp, entity_view.cpp and entity.h. Evidence is retained in entity-ghidra.json, entity-inline-assembly.json, entity-inline-ranges.json, entity-spatial-ghidra.json and sectree-types.json. CEntity target56/map12 differs from modern STL; no full class ABI match is claimed.

Construction initializes type-1, cleared positions/map/descriptor/sector, zero age/map index and false observer/destroyed flags. Destruction asserts Destroy already ran. Destroy cleans reciprocal views before setting its flag. Initialize clears only its own view map, so it can leave reciprocal entries when called on a live graph. View insertion refreshes existing ages without reestablishing missing reciprocal links. Target observer status controls insert/remove notification, and reencode permits callbacks to change observer state between calls.

PacketView requires a non-null sector; normal senders visit bound view descriptors then their own descriptor, honoring exclusions. Observer senders visit only themselves. Recipient observer flags are not separately filtered here. Tests use real DESC::Packet/buffers; entity-only/name suites instead link an explicit unreachable packet boundary.

UpdateSectree increments signed32 age with x86 register wrapping, directly traverses each neighbor list/set with preincremented iterators, refreshes in-range views, then processes stale/observer-change entries. Distance limit5500 uses weighted integer approximation246/102 divided256. Type2 objects bypass distance. Nearby type0 characters with no descriptor request StartStateMachine(1) when the observing type0 character has a descriptor, excluding character types3/9. Disassembly resolves misleading Ghidra bool propagation at character offset256. Null-sector character diagnostics preserve UpdateSectree:120. Unchanged observers retain stale entries; mode transitions process them and clear the change flag only when a sector is present.

Basic field accessor signatures come from old DWARF, including non-const getters. Caller instructions directly corroborate position getters, three-coordinate SetXYZ, descriptor/sector binding and map index. GetViewAge, IsObserverMode and the aggregate position-copy setter are reference-guided equivalents using established fields; their complete individual instruction ranges were not isolated. Those narrow inferences are distinct from emitted-body recovery.

SECTREE target32 comprises ID0/set4/list16/count20/clone24/attribute28. Modern tree/list representations differ. Its full data declaration and real constructor/Initialize are present; sector ownership destructor remains declaration-only. Attribute operations forward through real CAttribute. GetAttribute converts world coordinates via signed remainder6400 then division50; negative small remainders truncate towardzero. Set/Remove receive cell coordinates directly. CloneAttribute shares the pointer and marks clone=true; BindAttribute does not reset that flag. More negative cell accesses can retain the underlying legacy bounds defect and are not hardened or exercised unsafely.

Fixtures isolate sector ownership, character lifecycle/protocol/scheduling/chat and OS calls. Source-backed descriptor packet integration covers fanout; character/sector fixtures construct full declared objects, never reduced stand-ins. Default/O2 regressions and strict32-bit source syntax checks pass. No full server link/runtime or binary equivalence is claimed.


Sector population recovery: InsertEntity returnsfalse immediately when the entity is already bound to that sector, without repairing a missing set entry. Transfers erase the previous set directly, bind/insert the new sector, then increase new neighboring counts before decreasing old neighboring counts. Duplicate new entries log InsertEntity:139 but still succeed. New non-player characters activate only when the sector player count is positive, excluding character kinds3/9. RemoveEntity clears the sector pointer and decreases counts for players even when the set entry was absent. DecreasePC clamps/logs negatives at103 and stops every character in each zero-count neighbor. Tests verify overlapping-neighbor transfers avoid spurious stop calls, duplicate/missing entries, empty neighbor lists and repeated absent removals. State scheduler start/stop remains an explicit character fixture boundary.
