# Character identity and initialization helpers

CHARACTER::Create08127400 increments a process-wide signed32-bit counter, formats name/object-address/counter with a128-byte snprintf limit, computes CRC32 over the resulting string, assigns both VID fields, and assigns the name only for PCs. A non-PC call retains any previous name. Full PC names are retained even when CRC input is truncated. The supplied ELF stores counter seed172814 at082409a0 (bytes0ea30200); identity-quest-constants.json records the symbol and stored data. Wrapping arithmetic is explicit. Host percent-p formatting and pointer width differ from the target C runtime; host tests verify the algorithm with host-formatted pointers, not cross-platform CRC equality.

ResetStopTime081343c0 reads the actual millisecond clock; GetStopTime081343e0 returns the stored value without rereading. EndStateEmpty08138640 has an evidenced empty body and is no longer a fixture substitute. ClearKillCount08136790 uses actual CQuestManager::GetEventFlag for threeway_war_dead_count, preserving missing-zero and signed flag values.

InitMC08136be0 reads the heartbeat pulse five times, stores limits[10,60,60,604800,3600] multiplied by passes_per_sec, then subtracts each stored limit multiplied by passes_per_sec again. That double scaling is original behavior. GetMC08136cf0/GetMCL08136e30 return fields; SetMC08136d10 stores the current pulse. IsMCOK08136d30 compares unsigned elapsed pulses against the stored limit. GetMCLTime08136e50 divides limit and elapsed separately by unsigned passes_per_sec, then subtracts without a zero clamp. Expired timers can therefore wrap. Enum values0..4 and MI_MAX5 come from target DWARF. Callers must supply an in-range enum and nonzero heartbeat rate for division. Test-server diagnostics retain the original signed formatting.

Tests cover exact seeded identities, counter sharing across objects, long names, NPC name retention, wrapped timestamps, all five limits, expiry boundaries, unsigned wrap, diagnostic gating and actual quest flag changes. The test fixture supplies clocks and unrecovered full CHARACTER/quest lifecycle; the recovered methods are production code. CHARACTER Initialize/constructor/destructor remain pending; staged evidence is in character-lifecycle-next-ghidra.json.
