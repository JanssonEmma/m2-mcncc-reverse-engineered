# Base packet-information registry recovery — 2026-10-24

Scope: the old CPacketInfo base class in game/src/packet_info.cpp/.h. Twelve addressed records represent two constructor variants, three destructor variants and seven named methods (Set, Get, IsSequencePacket, GetElement, Start, End, Log). Complete decompilation is retained in packet-info-ghidra.json; focused constructor, End and Log assembly is in packet-info-assembly.json. Target SHA-256 is the same as validation-status.json. No original executable was run.

Observed behavior: constructor creates an empty map and clears current packet, leaving start time untouched. Set ignores duplicate headers before reading the name, copies names, initializes counters and adds one byte for sequence packets. Integer headers are unrestricted by a byte range. Get failure leaves outputs and current selection unchanged. IsSequencePacket and public GetElement do not change the current selection. The old API has no SetSequence declaration; newer IsSequence was not copied.

Start asserts a current packet and records the DWORD clock. End increments signed count with target32 wrapping and accumulates unsigned elapsed time/load; its packet pointer is captured before the clock call. Log iterates in numeric-header order, writes load using signed long formatting, but computes ratio from unsigned DWORD converted to double and signed count converted to double. This differs from the newer float-based code. Failed fopen silently returns; logging does not clear counters. Owned elements are deleted by the virtual destructor; std::map handles its own nodes. Compiler-generated old allocator/COW details are represented with normal C++ standard-library operations.

Layout: target SPacketElement is20 bytes (size0, string4, called8, load12, bool16). Target CPacketInfo is24 bytes (vptr0, map4 of size12, current16, start20). DWARF is retained in packet-info-types.json and summarized in packet-info-layout.md; tools/packet_info_types.py reproduces the focused extraction as JSON on stdout. Target structure default accessibility makes GetElement public; protected data fields explicitly carry accessibility2.

ABI limitation: modern MinGW libstdc++13 with -m32 and _GLIBCXX_USE_CXX11_ABI=0 reproduces the20-byte element but uses a24-byte std::map, making CPacketInfo36 bytes. The old24-byte containing-class layout requires the original library ABI or future compatibility work. This is explicitly not a successful target CPacketInfo ABI match; packet_info_abi.cpp verifies only element size/offsets. Scratch compiler assembly at work/packet_info/modern_layout.s established modern map24/class36. Do not pad or replace the map with a fake object to conceal this distinction.
