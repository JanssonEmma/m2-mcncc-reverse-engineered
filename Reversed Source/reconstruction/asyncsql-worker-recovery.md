The worker waits, moves producer pointers into the existing copy queue, adds the resulting total copy count, then attempts that many copy-queue heads. It continues the batch even when the end flag changes during the wait or query. Reconnection resets locale and caches server ID. Completed messages leave the copy queue, returned messages collect result descriptors and enter the result queue, and fire-and-forget messages are deleted with real record ownership. Finished and copied counters retain signed32-bit machine wrap.

The target reads cached message errno before choosing a retry branch. The current mysql_errno is fetched only after non-retry classification, then that message is completed despite the query failure. Retry codes1016,1034,1129,1130,1132,1133,1135,1138,1194 and2001..2006 instead post the semaphore and retain the head without updating errno or counters. The head can be attempted repeatedly within one copied batch. An empty producer queue causes CopyQuery to return-1 even when the copy queue still holds work; a new producer message can trigger processing of that backlog and make the copied counter count retained entries again. These old behaviors are deliberately retained rather than modernized.

At shutdown only producer entries are flushed. Failed flush queries retry based on cached errno, without fetching/updating current errno or posting another wake. Copied leftovers are not flushed. Producer entries arriving during a batch can therefore be processed by this final phase while pinned copied entries remain. Existing destructor non-ownership is unchanged.

Timing takes an initial sample even on immediate shutdown, then independent before/after samples for completed batched queries. The old threshold is200000 microseconds, unlike the newer reference. Seconds and microseconds are subtracted separately with32-bit wrap, without normalization: any positive seconds delta or microseconds delta greater than200000 emits the original LONG INTERVAL row. Exactly200000 does not. Retry attempts omit the end sample, and flush queries have no interval measurement. Clock and semaphore-wait return values are ignored as in the target.
