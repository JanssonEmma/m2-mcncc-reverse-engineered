# Character initialization and state/diagnostic dependencies

CHARACTER::Initialize08126dc0 is now a production implementation over the complete old class declaration. The target resets122 directly referenced fields, but this count is a reference audit, not proof of semantic equivalence. character-initialize-field-audit.json compares referenced field sets; tests independently check reset values, retained data and clock/state/quest interactions.

Initialization calls real CEntity::Initialize(0), clears points/instant-points/quickslots, sets position7, queues idle and initializes timing, pointers, flags, horse references, monarch cooldowns and two quest-backed counters. Its floating synchronization value subtracts the exact3.0f constant at082176b0. Eight millisecond samples occur in target order, plus one floating clock and five heartbeat reads. Unsigned deadline underflow is retained. Idle transitions are queued through the real CFSM rather than executed immediately.

It intentionally preserves VID/name, several containers, start/destination z coordinates, safebox-open z, empire, arena-observer flag, polymorph-maintain flag and other unassigned fields. Mobile authentication clears only its first byte. Only the chain-lightning exception set is cleared among the tested gameplay containers. It overwrites event handles before standing-state cancellation and is not a resource teardown API. Tests explicitly seed valid fixture data; they do not interpret indeterminate default bytes as defined values.

SetPosition08128a60 updates dead/standing bits and cancels dead then stun events for position7. Position0 sets the dead bit. Character type2 skips FSM selection. Other types select battle for5 and idle otherwise, logging only when the requested state differs from the current state, but always calling GotoState. Exact legacy diagnostic bytes are retained as escaped literals from position-diagnostic-strings.json.

MonsterLog0812fd10 is gated by test_server and absence of a source descriptor. It prepends the decimal VID and a closing parenthesis, formats with the old85-byte limit, emits packed chat header4/type0/source-ID/empire0 and calls real CHARACTER_MANAGER::PacketMonsterLog0818e360. The latter traverses live ordered registrations, accepts approximate distance<=6000, ignores map/observer state, skips missing recipient descriptors and broadcasts when source is null. Null registered pointers are an original caller-precondition violation, not silently filtered.

BeginStateEmpty08134be0 calls MonsterLog("!") and is no longer a fixture body. The old formatter can overflow its86-byte array or copy too much after truncation; original length behavior is preserved, and regression inputs stay within safe prefix-plus-text lengths. Packet tests use real temporary buffers and descriptors, exact boundary coordinates6244/6245, maximum safe text, event ordering and queued FSM state.

New character_initialize_regression uses the real CHARACTER constructor with explicit test-only destructor/quest lifecycle and real initialization, clocks, FSM and event-flag lookup. The CHARACTER constructor is now real; the destructor, quest Lua lifecycle and wider gameplay remain unresolved. Isolated descriptor/input suites link an aborting unreachable float-clock fixture; integration suites use real core timing or a controlled clock. Production implementations are not replaced by those fixtures.
